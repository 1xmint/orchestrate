# Release check: the 0005 build with and without the plugin (2026-10-01)

The release measurement for 0.18.0, required by AGENTS.md before a release.
The same three cases as docs/research/0005-baseline-0.17.2.md, the same
command. The tool now runs each arm three times by default; the baseline had one.

Command, per case:

    claude plugin eval evals --case <name> --trust-plugin --no-publish \
      --allow-tools Write Edit --scaffold

Tested tree: commit 44b82f8 on phase/0005-reaim (steps 0 to 6 and guard fix 3),
from a separate checkout. The version bump came later, so the eval prints the
plugin as "0.17.2"; the tree is the 0005 build. Guard fixes 4 to 8 came after
this run. They change only which shell lines the guard lets through, which
none of these cases exercises (no arm had a shell). Model in the runs:
claude-opus-5. Raw results are in evals/results/ (kept out of git).

## Results

Score is the mean over three runs; the baseline column is one run each.

| case | with plugin | without | difference | baseline (with / without) |
|---|---|---|---|---|
| costly-fork | 0.56 | 0.44 | +0.11 | 1.00 / 0.67 |
| wrong-goal | 1.00 | 0.67 | +0.33 | 1.00 / 1.00 |
| three-session-continue | 0.83 | 0.75 | +0.08 | 0.75 / 0.75 |
| misleading-bug | not run | not run | — | not run |
| failed-check-report | not run | not run | — | not run |

What decided each:

- **costly-fork.** With the plugin, runs scored 0.67, 0.67 and 0.33. Runs 1
  and 3 wrote a network server file; run 2 did not, but failed the judged "choice before cost" rule. Run 3 also failed
  `no-machinery`: plugin wording leaked into the reply. Without the plugin:
  0.33, 0.67, 0.33, and all three wrote the server file. The baseline's
  single 1.00 did not hold up over three runs.
- **wrong-goal.** With the plugin, all three runs raised the conflict before
  building and wrote no account code. Without it: 1.00, 0.67, 0.33; two runs
  wrote account code and one did not raise the conflict.
- **three-session-continue.** With the plugin: 0.75, 0.75, 1.00 (the log kept
  only the last lines, so run 1's 0.75 is read from the mean). Only run 3
  passed `continued-the-right-step`. Without: 0.75 in all three, failing that
  same rule each time.

Cost, list-price dollars including the judge: costly-fork 3.62, wrong-goal
2.18, three-session-continue 1.75. Total about 7.55, inside the 10 dollar cap.

## Not run, and why

`misleading-bug` (the step 5 ability test) and `failed-check-report` need a
shell, and `claude plugin eval` on this Windows machine refuses any shell
grant ("Sandbox required but unavailable"; full text in the baseline file).
They need Linux, macOS or WSL with the sandbox backend.

## How far to trust this

- Three runs per arm against one in the baseline. The differences are small
  and the runs vary widely (costly-fork without the plugin ran 0.33 to 0.67),
  so read the direction, not the size: the plugin was ahead or level in every
  case, never behind.
- costly-fork is the weak spot. In two of three runs, Claude with the plugin
  still wrote a server file, which the case says to hold until the cost is chosen, and one reply
  leaked plugin wording. Both are gaps for the next audit.
- No shell in any arm, so "it works" in these replies is read, not run.
