  copy, the installed copy disabled, `--model sonnet`, headless `-p`,

  state lives under `<home>/.claude/orchestrate`; it was read, never written.
- One fresh git repo per run under `<temp>/o3/live15/<name>`; streams, debug
  logs and the scan scripts stay there and are not copied here.
- What the plugin told the lead is read from the debug logs (`Hooks: Parsed
  initial response`); `#N` is the event number in that run's stream, `L N` a
  debug-log line. Hand-back sizes are the bytes of the `SubagentHandback`
  message each helper sent. The "session record" is the plugin's own state
